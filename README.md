# React-AI-ChatApp

A simple AI-powered chat application built with **React.js** that connects to multiple AI models through the **AgentRouter API gateway**.

## ✨ Features

* **Real-time AI chat** inside a modern web UI.
* Responsive **Dark Mode** design.
* Clean API integration using Native JavaScript **Fetch**.
* Dynamic message handling and history management.

## 🚀 Getting Started

### Prerequisites

* **Node.js** installed on your machine.
* An AgentRouter API Key → [agentrouter.org](https://agentrouter.org)
